# Happy Birthday Farida 🎂

A small birthday page for Farida, January 3. It opens with a password gate and then shows the birthday message with candles and confetti.

**Password:** `dida`

## Publish on GitHub Pages

1. Create a new repository on GitHub, for example `farida-birthday`. Set it to **Public**, because GitHub Pages on a free account needs a public repo.
2. Upload the files `index.html`, `README.md`, and `.nojekyll` to the repository (drag and drop on the GitHub page works).
3. Go to **Settings → Pages**.
4. Under **Build and deployment**, set **Source** to **Deploy from a branch**, choose the `main` branch and the `/ (root)` folder, then click **Save**.
5. After a minute or two, the site will be live at:
   `https://<your-username>.github.io/farida-birthday/`

## Note

The password is stored inside the page, so it only keeps out casual visitors. It is fine for a surprise, but it is not real security.
